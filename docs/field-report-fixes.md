# v1.4.0 实测反馈修复

依据用户提供的实测报告修复三项已确认缺陷。未连接线上 VPS，未把报告中的 IP、域名、账号或环境细节提交到仓库。

- Reality：提取 `scan_safe_targets`，CLI scan（供菜单与非交互首选使用）和 `select_target(auto)` 共用同一过滤。过滤高风险域名、私网、不可用或字段不全的结果；空结果在选择前失败。保留手动创建时的安全复核。上游可能忽略 candidates 参数，因此明确其只是请求提示，不假设调整 JSON 格式就能限制清单。
- 系统升级：重启标志检查不再成为函数隐式失败返回值。成功升级固定返回 0；APT 失败仍由 strict mode 中止；取消不执行升级。
- 自测隔离：抽取服务归属查询，测试用明确的归属 fixture 替换宿主文件检查。分别覆盖无管理服务和存在项目 landing 服务两种情况，不改变生产环境的服务识别路径。

新增回归覆盖：Cloudflare 排首位、过滤后无候选、CLI 与自动/手动首选一致、升级成功有/无重启标志、取消、服务归属 fixture。

TcpQuality rootfs 内失败尚未定位；Lucky 监听加固、WS 弃用提示均保持原行为。未改 Docker 源、DNS、SSH 或 DD 路径。真实 VPS 需针对这三项修复重新验收。
